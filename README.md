<h1>Connection v1</h1>
<h3>what it is + preview</h3>
<p>Connection is a website that shows local time , and allows you to log the moment to remember it later (saves locally for now), with a changing background overlay to match time(built with html , css and js)</p>

<h3>how to use</h3>
<p>go to <a href="https://nozomi-rou.github.io/Connection/">this website </a> , to add logs write your log then press new , to delete go to desired log and press del</p>
